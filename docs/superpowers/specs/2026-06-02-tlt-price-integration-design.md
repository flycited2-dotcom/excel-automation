# Интеграция собственного прайса (ТЛТ) как третьего источника

**Дата:** 2026-06-02
**Статус:** утверждён

## Цель

Добавить собственные товары пользователя (выгрузка из 1С, префикс артикулов
`Ту-`) в общий прайс-лист. Цены берутся 1:1 — **наценка не применяется**
(в источнике уже финальная розничная цена). Товары распределяются по
существующим группам прайса. Прайс обновляется периодически — пользователь
просто кладёт свежий файл в отдельную папку.

## Источник данных

Папка `price_TLT_input/`, берётся самый свежий `.xlsx`/`.xls`
(временные `~$...` игнорируются). Если файла нет — источник пропускается,
основной прайс работает как раньше.

Формат файла (`Прайс_ТЛТ_*.xlsx`):
- Колонка **A** — артикул (`Ту-00...`)
- Колонка **E** — наименование; строки-категории (`3.01 Чайники
  электрические`) идут разделителями и **не имеют цены**
- Колонка **N** — цена (`1 235,00`, неразрывный пробел + запятая)

Парсинг: строка с ценой в N → товар; строка без цены → текущая категория.
У категории отрезается числовой префикс (`3.01 `, `п11. `, `2. `) регуляркой
`^\s*[\dпП][\d.]*\.?\s+`. Цена `1\xa0235,00` → `1235.0`.

## Распределение по группам

Таблица соответствий в редактируемом файле
`соответствие_категорий_ТЛТ.xlsx` (колонки: *Категория ТЛТ* | *Группа
прайса*). Ключ — очищенное имя категории как в источнике (включая опечатки,
напр. «элеткро»).

Предзаполнение:

| Категория ТЛТ | Группа прайса |
|---|---|
| Чайники электрические | Электрочайники |
| Блендеры | Блендеры |
| Блендеры настольные(стационарные) | Блендеры |
| Мясорубки | Мясорубки |
| Микроволновые печи, СВЧ | Микроволновые печи |
| Кофемашины, кофеварки | Кофеварки, кофемашины |
| Кофемолки | Кофемолки |
| Утюги | Утюги и гладильные системы |
| Колбовые пылесосы | Пылесосы колбовые |
| Фены | Фены |
| Бритвы | Машинки для стрижки и триммеры |
| Машинки для стрижки | Машинки для стрижки и триммеры |
| Плитки настольные, элеткро, газ, индукция | Плитки настольные |
| Сушилки для овощей | Сушилки для овощей и фруктов |
| Смесители | Кухонные смесители |
| Прочее оборудование(под объекты) | Прочая мелкая техника |

Категория без соответствия → отдельная группа с именем категории, уходит
в конец прайса (позиция не задана). Ничего не теряется, сразу видно, что
надо дописать строку в таблицу.

## Бренд (авто-определение)

Колонки бренда в источнике нет. Множество брендов = бренды из прайса
поставщика ∪ доп.список `config.json["tlt_extra_brands"]`. Поиск по словам
в названии (длинные бренды первыми, чтобы «Galaxy Line» не схлопывался в
«Galaxy»; границы слова — чтобы избежать ложных вхождений). Не нашёлся —
бренд пустой.

## Интеграция в конвейер

Новый источник вливается в общий `df` в `transform()` рядом со СплитХабом.
Поля: `article, group, brand, name, price_in, price_out`. `price_out`
проставляется сразу (= цена), благодаря чему `apply_pricing` пропускает
наценку (та же логика, что у фикс-цен HOMELINE). Товары встают в свою
группу после позиций поставщика; нумерация, чередование, авто-высота —
штатно через `build_pricelist`.

## Конфигурация (`config.json`)

- `tlt_input_dir`: `"price_TLT_input"`
- `tlt_category_map_file`: `"соответствие_категорий_ТЛТ.xlsx"`
- `tlt_extra_brands`: список брендов мелкой техники

## Вне рамок

- Дедупликация с прайсом поставщика (артикулы не пересекаются: `Ту-` vs `UT-`).
- Чистка хвостов `<...>` в названиях — оставляем 1:1.
