# Дизайн: интеграция прайса СплитХаб

## Цель

Добавить в итоговый прайс-лист позиции из второго источника — прайса поставщика кондиционеров СплитХаб. Одновременно исключить кондиционеры из основного прайса (priceopt) и исправить сортировку сушильных машин.

## Изменения в config.json

Добавляются два новых поля:

```json
"splithub_file": "splithub-price.xlsx",
"group_after": {
  "Сушильные машины": "Стиральные машины"
}
```

- `splithub_file` — путь к файлу прайса СплитХаб относительно папки проекта. При обновлении цен пользователь заменяет этот файл.
- `group_after` — словарь для «прикрепления» группы к позиции сразу после другой группы, без правки Excel-файла с порядком.

## Структура прайса СплитХаб

Файл содержит один лист «Прайс» со следующей структурой:
- **Строки-заголовки бренда**: col0 = название бренда, col1 = пусто
- **Строки-подзаголовки серии**: col0 = пусто, col1 = название серии
- **Строки товаров**: col0 = №, col1 = ID, col2 = Модель, col3 = Описание, col4 = Цена ₽, col6 = Наличие

## Классификация по группам

При разборе отслеживаются текущий бренд и текущая серия. Группа определяется по ключевым словам в названии серии:

| Ключевые слова в серии | Группа |
|---|---|
| `on/off`, `on-off` (и отсутствие признаков полупрома) | Классические сплит-системы |
| `inverter`, `invertor`, `inv` (и отсутствие признаков полупрома) | Инверторные сплит-системы |
| `Кассетная`, `Напольно-потолочная` | Полупромышленные сплит-системы |
| Секции `Медная труба` и `Расходники` | Расходные материалы для монтажа (медь) |

Для классики/инверторов: если в описании товара (col3) есть «Инвертор» — инверторный, «On/Off» — классический (резервная проверка).

## Наценка

Цены из прайса СплитХаб применяются 1:1 (наценка 0%). `price_out = price_in`.

## Формат возвращаемого DataFrame

`read_splithub_price()` возвращает DataFrame с теми же столбцами, что и основной прайс:

| Столбец | Источник |
|---|---|
| `article` | col2 (Модель) |
| `group` | определяется по серии |
| `brand` | текущий заголовок бренда |
| `name` | col3 (Описание) |
| `price_in` | col4 (Цена ₽) |
| `price_out` | = price_in |

## Сортировка внутри группы «Расходные материалы для монтажа (медь)»

При разборе каждой позиции присваивается числовой `subsection_order` по подразделу:

| Подраздел | Порядок |
|---|---|
| Медная труба | 1 |
| Изоляция | 2 |
| Кронштейны | 3 |
| Прочее (ленты и пр.) | 4 |
| Дренаж | 5 |
| Кабель (ПВС из «Прочее») | 6 |
| Крепёж (болты, гайки, дюбели) | 7 |
| Фреон (из «Прочее») | 8 |

ПВС и Фреон выделяются из подраздела «Прочее» по ключевым словам в названии модели.

DataFrame перед передачей в `build_pricelist` сортируется по `(group_sort_key, subsection_order)`.

## Изменения в transform.py

### 1. Новая функция `read_splithub_price(filepath)`

Разбирает файл СплитХаб, возвращает DataFrame в стандартном формате. Содержит всю логику определения бренда, серии, группы и `subsection_order`.

### 2. Изменение в `read_supplier_price()`

После загрузки DataFrame — фильтрация:
```python
EXCLUDE_GROUPS = {'Кондиционеры инверторные', 'Кондиционеры он/офф'}
df = df[~df['group'].isin(EXCLUDE_GROUPS)]
```

### 3. Изменение в `apply_pricing()`

Позиции с `price_out` уже проставленным (из СплитХаб) пропускают логику наценки. Реализуется через флаг или предустановленный `price_out` в DataFrame.

### 4. Изменение в `transform()`

После чтения основного прайса:
```python
splithub_path = BASE_DIR / config.get('splithub_file', 'splithub-price.xlsx')
if splithub_path.exists():
    df_splithub = read_splithub_price(splithub_path)
    df = pd.concat([df, df_splithub], ignore_index=True)
```

### 5. Изменение в сортировке групп (`build_pricelist`)

Функция `group_sort_key` учитывает `group_after` из конфига:
```python
def group_sort_key(g):
    pos = group_order.get(g) or group_order.get(g.rstrip())
    if pos is None and g in group_after:
        parent = group_after[g]
        parent_pos = group_order.get(parent) or group_order.get(parent.rstrip())
        if parent_pos is not None:
            pos = parent_pos + 0.5
    return pos if pos is not None else max_order
```

## Что нужно сделать вручную

После реализации пользователю нужно добавить 4 новые группы в файл `Места_по_группам_товара_исправлено.xlsx` с желаемыми порядковыми номерами:

- Классические сплит-системы
- Инверторные сплит-системы
- Полупромышленные сплит-системы
- Расходные материалы для монтажа (медь)

## Критерии успеха

1. В итоговом xlsx нет позиций из групп `Кондиционеры инверторные` / `Кондиционеры он/офф`
2. Присутствуют все 4 группы из СплитХаб с правильными позициями
3. Цены в группах кондиционеров совпадают с ценами в `splithub-price.xlsx`
4. Расходники идут в порядке: медь → изоляция → кронштейны → прочее → дренаж → кабель → крепёж → фреон
5. Сушильные машины стоят сразу после стиральных
6. При замене `splithub-price.xlsx` на новый файл — цены обновляются без правки кода
