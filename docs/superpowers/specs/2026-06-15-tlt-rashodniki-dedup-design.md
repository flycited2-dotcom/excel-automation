# Дедупликация расходников ТЛГ/СплитХаб и раскладка прочих ТЛГ-категорий

**Дата:** 2026-06-15
**Статус:** утверждён

## Проблема

После включения собственного прайса (ТЛГ) как источника часть его категорий
дублирует расходники из прайса СплитХаб (медная труба, дренаж, крепёж,
кронштейны и т.п.). Это одни и те же товары, но имена сохранены по-разному —
**точных совпадений имён 0** (проверено: 50 расходников ТЛГ против 52 СплитХаб).
Поэлементная дедупликация по имени невозможна без семантического матчинга
(парсинг диаметра/длины/стенки), который хрупок. Кроме того, 19 ТЛГ-категорий
вообще не сопоставлены и сваливаются в конец прайса разнобоем.

## Решение (дедуп на уровне источника)

Расходники берём **только из СплитХаб** (там уже чистые имена и настроенная
сортировка подсекций). Дублирующие ТЛГ-категории **исключаем** целиком.
Остальные ТЛГ-категории раскладываем по канонике прайса.

### A. Исключить из ТЛГ (8 категорий)

Медная труба · Дренаж · Изоляция для трубы · Крепеж (дюбеля, болты, гайки) ·
Кронштейны · Лента тефлоновая,скотч · Провод, вилки · Фреон, MAPP Gas

### B. Новый блок после расходников, перед КБТ

Порядок шапки: сплит-системы (1.0–1.6) → расходники СплитХаб (2.0) →
**этот блок** → стиральные машины (group_order=3) и далее КБТ.

| ТЛГ-категория | Группа прайса | `group_positions` |
|---|---|---|
| Стабилизаторы напряжения 80-260В | Стабилизаторы напряжения | 2.1 |
| Стабилизаторы напряжения 100-260В | Стабилизаторы напряжения | 2.1 |
| Стандартные генераторы | Генераторы | 2.2 |
| Мотоблоки, двигатели, культиваторы, мотобуры, компрессоры | Мотоблоки и садовая техника | 2.3 |

Оба стабилизатора сливаются в одну группу «Стабилизаторы напряжения».

### C. Вписать в существующие группы КБТ

| ТЛГ-категория | → Группа прайса |
|---|---|
| Холодильники капельные, Defrost | Холодильники с верхней морозильной камерой |
| Телевизоры, медиплееры, кронштейны | Телевизоры 27"- 32" |

### D. Вниз, в конец прайса (без позиции)

Электроника, МФУ, ноутбуки, переферия · Инструменты · Запчасти ·
Разное (запчасти, клапана, химия). Остаются 4 отдельными группами,
сопоставление не задаётся — штатно падают в конец.

## Механика реализации

1. **`соответствие_категорий_ТЛТ.xlsx`** — добавить строки:
   - раздел A → спецзначение группы `(исключить)`;
   - разделы B/C → целевые группы из таблиц выше;
   - раздел D — не трогаем (падает в конец сам).
2. **`transform.py`** — в `read_tlt_price` (или сразу после маппинга) строки,
   у которых сопоставленная группа равна `(исключить)`, выбрасываются из `df`.
   Маркер задаётся константой `_TLT_EXCLUDE = '(исключить)'`.
3. **`config.json` → `group_positions`** — добавить:
   `"Стабилизаторы напряжения": 2.1`, `"Генераторы": 2.2`,
   `"Мотоблоки и садовая техника": 2.3`.

## Проверка

- Расходников ТЛГ в итоге — 0 (есть только СплитХаб).
- Группы «Стабилизаторы напряжения», «Генераторы», «Мотоблоки и садовая
  техника» стоят между расходниками и стиральными машинами.
- Холодильник/телевизор ТЛГ попали в соответствующие группы КБТ.
- Электроника/Инструменты/Запчасти/Разное — в конце прайса.

## Вне рамок

- Семантический (нечёткий) матчинг расходников между источниками.
- Изменение прайса СплитХаб.
